# 🔐 프로젝트 이름

> 가상화 환경에서 네트워크 트래픽을 분석하고 보안 위협을 탐지하는 보안 모니터링 시스템

---

## 📌 프로젝트 소개

가상화 기반 네트워크 환경에서 발생하는 트래픽을 분석하고
IDS를 통해 보안 위협을 탐지하는 시스템을 구축한 프로젝트입니다.

---

## 🛠 사용 기술

* OpenStack / KVM
* Open vSwitch
* Suricata (IDS)
* Jenkins
* Ubuntu Server

---

## 🏗 시스템 구성

User
↓
Web Server (VM)
↓
Open vSwitch
↓
Suricata (IDS)
↓
Log Server

---

## ⚙ 주요 기능

* 네트워크 트래픽 모니터링
* IDS 기반 공격 탐지
* 보안 로그 수집 및 분석

---

## 👨‍💻 담당 역할

* 가상화 환경 구축 (OpenStack)
* Suricata IDS 구축 및 룰 설정
* 네트워크 트래픽 분석

---

## 📊 결과

* 공격 트래픽 탐지 가능
* 보안 이벤트 로그 확인 가능
